# GateHop

Free Apple ID companion iOS app (`GateHop.ipa`) that fetches live OpenVPN servers from **VPNGate** (`https://www.vpngate.net/api/iphone/`), probes live TCP latency from your iPhone, ranks the fastest node (globally or in a custom country), auto-refreshes every 5 minutes, and exports `.ovpn` profiles straight into **OpenVPN Connect**.
